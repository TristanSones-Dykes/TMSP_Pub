# phobius

This directory contains summary .csv results of Phobius predictions for the first 60 amino acids of all species considered.

All the .csv files contain length predictions of the h-region only from the Phobius output.

Except, `S_Cerevisiae_fullSignal.csv` contains length predictions of the full signal peptides (n-region, h-region, c-region combined) to compare with DeepTMHMM and SignalP6.0.

See `src/phobius.py` for full details of code for feature extraction.
